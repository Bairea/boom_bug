# 🧨 擦炮虫虫实验室 · Boom Bug Lab

> **微型灾难实验室**：在透明盒子里摆放发条玩具虫和擦炮/窜天猴/冲天炮，装上牙签、大头针、绳子、胶水，
> 按下「点燃」，旁观确定性物理规则把你的恶念演化成一场连锁灾难 —— 自动生成
> 「事故调查报告 THE INCIDENT」+ 慢速回放 + 分享码。

源于 `prd1.txt` 的头脑风暴，按设计文档分 7 个阶段开发与测试。

## 快速开始

```bash
npm start          # 启动零依赖静态服务器 → http://localhost:8123
npm test           # 44 个无头测试（模拟核心全量覆盖）
```

无需安装任何依赖（Node ≥ 18 即可，本项目在 Node 24 开发）。

## 玩法（30 秒上手）

1. **摆放**：左侧工具箱选物品，点击盒子放置；窜天猴/冲天炮按住拖拽瞄准。
2. **改装**：点「牙签/大头针/胶水」再点某个爆炸物安装头部配件；点「绳子」连接两个物体（超载会断）。
3. **点燃**：按「🔥 点燃！」依次引燃，或运行中点击任意未点燃的爆炸物随时点火。
4. **目睹失控**：蟑螂逃窜、蝗虫乱跳、炮仗殉爆……平静 3 秒后自动生成事故报告。
5. **回放 / 再来一次 / 分享**：慢放复盘；「再来一次」同种子完全复现；「🔗 分享」把整个实验压进 URL，
   对方打开就是同一场事故（确定性模拟 = 分享码只有几百字节）。

## 架构

```
src/
  sim/      确定性模拟核心（零 DOM 依赖，Node 可跑）
            rng/mulberry32 · body/圆形刚体 · world/碰撞与绳约束
            bugs/状态机AI · explosives/引信推力爆炸连锁 · accessories/配件修饰器
  game/     catalog/物品数值表 · encode/分享码 · replay/回放与事故报告 · scenario/预设
  ui/       render/Canvas玩具风渲染 · particles/粒子震屏 · editor/摆放瞄准 · main/状态机
test/       分阶段测试 P0~P7（node:test，无头）
```

三条铁律（来自 PRD 的设计公式「简单规则 × 复杂交互 × 随机初始状态 × 高反馈」）：

1. **确定性**：模拟层禁用 `Math.random`/`Date.now`，一切随机走种子 RNG —— 同种子+同操作 = 同灾难，
   回放/分享码/对照实验全部建立在它之上（有专门测试守护）。
2. **半物理**：爆炸=参数化冲击球（冲量+伤害+连锁引燃），物体只有物理属性没有特化规则
   （牙签=高穿透轻质，而不是"牙签专杀蟑螂"）。
3. **玩具世界**：被"击倒"= 翻壳冒火花抽搐的机械故障，无血腥（规避虐虫观感，PRD §18）。
