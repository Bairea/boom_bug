# 🧨 擦炮虫虫实验室 · Boom Bug Lab

> **微型灾难实验室**：在透明盒子里摆放发条玩具虫和擦炮/窜天猴/冲天炮，装上牙签、大头针、绳子、胶水，
> 按下「点燃」，旁观确定性物理规则把你的恶念演化成一场连锁灾难 —— 自动生成
> 「事故调查报告 THE INCIDENT」+ 慢速回放 + 分享码。

源于 `prd1.txt` 的头脑风暴，按设计文档分 7 个阶段开发与测试。

## 快速开始

```bash
npm install        # 仅一个 devDependency：TypeScript
npm start          # tsc 编译 → 启动静态服务器 → http://localhost:8123
npm test           # tsc 类型检查 + eslint + 152 个无头测试（模拟核心全量覆盖）
```

源码是 `src/**/*.ts`（严格模式）；`tsc` 只做类型擦除、原地输出原生 ESM（`src/**/*.js`，已 gitignore），
**没有打包器、没有框架** —— 浏览器加载的仍是平铺的 ES Module。

## 玩法（30 秒上手）

1. **摆放**：左侧工具箱选物品，点击盒子放置；窜天猴/冲天炮按住拖拽瞄准。
2. **改装**：点「牙签/大头针/胶水」再点某个爆炸物安装头部配件；点「绳子」连接两个物体（超载会断）。
3. **点燃**：按「🔥 点燃！」依次引燃，或运行中点击任意未点燃的爆炸物随时点火。
4. **目睹失控**：蟑螂逃窜、蝗虫乱跳、炮仗殉爆……平静 3 秒后自动生成事故报告。
5. **回放 / 再来一次 / 分享**：慢放复盘；「再来一次」同种子完全复现；「🔗 分享」把整个实验压进 URL，
   对方打开就是同一场事故（确定性模拟 = 分享码只有几百字节）。

预设场景：**案例1 连环风暴**（连锁≥3）、**案例2 蟑螂狩猎**（击倒≥4）、**案例3 破甲实验**（击穿装甲）、**案例4 黏液保龄球馆**（一爆双响）、**案例5 空中狩猎**（击落苍蝇）、**案例6 擦炮冰壶**（水障+冰面滑行，一击掀翻≥3）、**案例7 火烧连营**（火焰沿木板链传播）、**案例8 油锅**（油中爆炸放大，一击全倒）、**案例9 气球空袭**（吊炮穿过苍蝇巡航带，择机点燃/遥控引爆）。苍蝇会被附近的爆炸物吸引聚拢 —— 吊炮就是移动的诱蝇灯。

**📅 每日实验**：工具栏点「每日实验」，全世界同一天拿到同一份种子+布局（按日期确定性生成，四主题轮换：连环/火箭/材料/害虫日）；战绩按日期入账，「对照上次」自动变成"和今天上一局比"，重跑同日同局会得到「与上次完全一致——确定性 ✓」。

**运行中还能玩**：点击未点燃的爆炸物随时点火；空白处拖拽扔进一根点着的炮仗（带重力弹道预测）；殉爆会让连锁真正滚起来。

## 架构

```
src/
  sim/      确定性模拟核心（零 DOM 依赖，Node 可跑）
            rng/mulberry32 · body/圆形刚体+判别联合Body · world/碰撞与绳约束
            bugs/状态机AI · explosives/引信推力爆炸连锁 · accessories/配件修饰器
            events/模拟事件联合类型
  game/     catalog/物品数值表 · encode/分享码与命令流 · replay/回放与事故报告 · scenario/预设
  ui/       render/Canvas玩具风渲染(辉光/氛围) · particles/加法粒子 · fx/挤压弹跳 · editor/摆放瞄准 · main/状态机
test/       分阶段回归测试（node:test，无头，只 import 编译产物）
```

三条铁律（来自 PRD 的设计公式「简单规则 × 复杂交互 × 随机初始状态 × 高反馈」）：

1. **确定性**：模拟层禁用 `Math.random`/`Date.now`，一切随机走种子 RNG —— 同种子+同操作 = 同灾难，
   回放/分享码/对照实验全部建立在它之上（有专门测试守护）。三角/距离计算统一走
   `sim/dmath.ts`（dhypot/dsin/dcos/ddatan2）：ECMA 不规定 `Math.sin/cos/atan2/hypot` 的实现，
   各引擎可差 1+ ULP 并翻转布尔判定，dmath 只用 IEEE 754 规格化运算，跨浏览器/跨引擎
   逐位一致 —— 分享码在 Chrome/Firefox/Safari 重建出同一场事故，也是未来"一套代码多端"
   （Electron/Tauri/Capacitor 必然混用 V8 与 JavaScriptCore）的前置条件。
   守护测试：位级冻结向量 + 精度对照 + sin²+cos²=1 自洽 + 静态扫描（p29）。
2. **半物理**：爆炸=参数化冲击球（冲量+伤害+连锁引燃），物体只有物理属性没有特化规则
   （牙签=高穿透轻质，而不是"牙签专杀蟑螂"）。
3. **玩具世界**：被"击倒"= 翻壳冒火花抽搐的机械故障，无血腥（规避虐虫观感，PRD §18）。

类型模型（TS 严格模式）：`Body` 按 `kind` 判别联合（`ExplosiveBody/BugBody/PropBody`），各自的 data
必需字段在 `ExplosiveData/BugData/PropData` 收紧；跨 kind 读取的运行时状态放 `EntityDataBase` 可选层；
模拟事件是 `SimEvent` 17 种联合、命令流是 `Ignite/Throw` 判别——多态字段打错名直接编译失败。

## 视觉与手感（R89-R293）

表现层大翻新，模拟层一字未动（确定性不受影响）：

- **场景氛围**：分层桌面背景（渐变+台灯辉光+暗角，DOM 环境预渲染缓存）、玻璃盒质感
  （后壁光/地面沉降/对角反光/金属渐变边框+螺丝）、双层软阴影、焦痕层次。
- **辉光粒子**：加法混合（`lighter`）+ 预渲染辉光精灵——三层爆闪、双描边冲击环、
  渐冷色火花、余烬上飘、纸屑碎片、火场暖烟、落水水花、冰霜滑痕、环境微尘；引信与尾焰辉光。
- **手感 juice**：trauma² 平滑震屏（分层正弦+小幅滚转，替换每帧随机抖动）、大威力顿帧
  hit-stop（时间缩放实现，不碰模拟）、爆炸全屏白闪+方向性推镜、squash & stretch
  （速度对齐拉伸 + 着陆骤停检测 + 击倒/裂甲/钉住/蝗虫起跳弹跳弹簧）、慢镜头时间涟漪
  与镜头向爆心缓推、HUD 连锁数增长脉冲、新纪录全屏彩带雨。
- **物件美术**：全部物件渐变/高光/倒角重绘（蟑螂壳、炮仗纸筒、砖面、水面闪点、
  木板火舌、礼盒缎带、金属拉丝、冰面棱面、油面虹彩、苍蝇翅残影……），
  顺手修复气球双重位移 bug；虫虫 idle 生命感（苍蝇悬停浮动、蟑螂触角轻摆、蜗牛眼柄摇曳、
  蟑螂恐慌速度线）；材质区环境动效（水涟漪/油气泡/冰闪烁/沙风纹）；引信"越烧越短"。
- **回放完整化**：回放按完整事件流重演表现层反馈（焦痕/浮字/震屏/白闪/击倒火花/气球橡胶
  碎片/断绳……），不再只是爆炸粒子+音效。
- **界面 chrome**：对齐 Vercel Web Interface Guidelines——color-scheme dark、渐变标题、
  统一按钮体系（hover 抬升 / active 按压 / focus-visible 光环）、玻璃拟态状态胶囊与 HUD 芯片、
  报告卡级联入场+滚动计数+标题微光、图标按钮补 aria-label、静音按钮 aria-pressed、
  help/report 补 dialog 语义、`prefers-reduced-motion` 全链路降级（画布特效同步降压）。
- **交互可读性**：运行中悬停可点燃物蓝圈/可引爆物橙圈、绳子连接预览虚线（蚂蚁线流动）、
  删除工具悬停红圈、空场景中央引导语、投掷弹道落点标记+力度弧、
  弹道落点入水/入油预警圈（蓝=熄灭/橙=爆燃放大）、场景切换淡入、摆放落地弹跳、
  全屏模式（⛶/F）、标签页标题随场景与运行状态更新、每日实验未完成呼吸点。
- **性能**：加法混合与预渲染缓存下实测 0.4ms/帧（60fps 预算的 1/40）；高 DPI 屏幕内部
  分辨率按 devicePixelRatio 自适应（文字/线条锐利一倍）；后台标签页跳过渲染省电。
