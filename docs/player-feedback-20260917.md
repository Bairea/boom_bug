# 玩家试玩反馈与改进清单（2026-09-17 晨）

以玩家身份完整试玩：案例1 全流程（摆放→点燃→事故报告→回放）、自由实验摆放、
运行中拖拽投掷。以下按「玩家痛点 → 建议 → 状态」整理。

## 实测发现的问题（按优先级）

### P1 报告面板挡住顶栏，且没有关闭按钮
- **现象**：事故报告弹出后覆盖顶栏右侧的「？」「🔊」「🔗 分享」三个按钮
  （面板 `top:12px`，正好压在 44px 高的 header 上）。面板上没有 ✕，
  玩家只能点「继续改造 / 再来一次」才能关掉它。
- **建议**：面板下移到 header 之下；右上角加 ✕ 关闭（回到编辑）。

### P1 运行中"点击未点燃爆炸物点火"命中圈太小
- **现象**：运行中点火判定半径是 6 世界像素（画布 960 宽），换算到屏幕
  只有约 8px，炮仗本身还在乱蹦，实战中几乎点不中，提示语却鼓励玩家这么干。
- **建议**：判定半径放宽到 ~14（约为炮仗视觉半径的 2 倍），并提成
  `Simulation.pickIgnitable(x,y,r)` 以便无头测试。

### P2 回放不能跳过、不能倍速
- **现象**：回放固定 0.5× 速，一段 5.6s 的事故要陪看 ~11s；想再看报告
  只能干等进度条走完。空格在回放中不起任何作用。
- **建议**：回放中显示「⏭ 跳过」按钮（点击/空格直达报告）；再来一个
  0.5×/1× 倍速切换，想细看的人手动加速。

### P2 工具箱太长，删除/冰面/金属板/沙坑沉在滚动区底部
- **现象**：900px 高的屏幕也要滚动才能看到 冰面/金属板/沙坑/删除；
  「删除」是最常用的工具之一却排在最后一项。
- **建议**：道具区改两列网格压缩纵向空间。

### P3 小Graffiti（顺手项）
- 报告「对照上次」首局无说明：可加「首局，暂无对照」一行（首局隐藏即可，现状可接受）。
- 编辑模式摆放的物体悬浮不动（物理冻结），新玩家可能误以为是 bug —— 状态栏
  提示里补一句「摆放时物理暂停，点燃后才开跑」。
