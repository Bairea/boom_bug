# 擦炮虫虫实验室（Boom Bug Lab）设计文档

日期：2026-08-30 ｜ 来源：prd1.txt ｜ 状态：v1（自主头脑风暴收敛稿，待用户复核）

## 1. 一句话定位

> **微型灾难实验室**：玩家在一个透明盒子里摆放"发条玩具虫"和擦炮/窜天猴/冲天炮，
> 装上牙签、大头针、绳子、胶水，按下"点燃"，然后旁观一套确定性物理规则
> 把自己的恶念演化成一场谁也预料不到的连锁灾难 —— 最后自动生成
> 「事故调查报告 THE INCIDENT」+ 回放 + 分享码。

对应 PRD 核心公式（§24）：**简单规则 × 复杂交互 × 随机初始状态 × 高反馈 = 涌现玩法**。

## 2. 设计支柱（自 PRD 提炼，全部可执行化）

| # | 支柱 | PRD 出处 | 落地方式 |
|---|------|---------|---------|
| 1 | 确定性物理 + 随机初始行为 | §2 | 固定步长(1/60s)模拟 + 种子 RNG；同一 seed+操作序列 = 完全相同的灾难 |
| 2 | 半物理，"像真的"而非"是真的" | §10-11 | 自研简化物理：爆炸=冲量+伤害+引燃的参数化球体，不做流体/破碎 |
| 3 | 物体只有物理属性，没有特化规则 | §24 | 牙签=穿透+轻，胶水=强连接，不做"牙签专杀蟑螂"式设定 |
| 4 | 回放是核心卖点不是附属 | §4 | 事故报告(连锁数/击倒数/意外事件) + 慢速回放 + URL 分享码 |
| 5 | 玩具世界，规避"虐虫"观感 | §18 | 全部是发条玩具虫：被"击倒"= 翻壳冒火花抽搐，无血腥 |
| 6 | 30秒~2分钟一个实验 | §21 | 编辑即点即放；一键"再来一次"(同种子)/"新实验"(新种子) |

## 3. 技术选型（三选一，已定 A）

- **A. 原生 JS + Canvas 2D + 自研确定性物理（选定）**
  - 理由：①确定性 = 回放/分享码极小（seed+操作流，纯 URL hash，零后端）；②模拟核心无 DOM 依赖，Node 无头测试；③半物理参数完全自己掌控，好调"手感"；④零依赖、零构建，双击即玩、易分享。
  - 代价：物理手写。但 2D 圆形刚体 + 矩形盒边界规模很小，可控。
- B. Phaser + Matter.js：开发快，但引擎内调"半物理手感"受限，确定性回放码体积大、无头测试链路重。否决。
- C. Three.js 3D：表现力强但复杂度 10 倍，MVP 否决（后续美术升级可再评估）。

## 4. MVP 范围（PRD §22 + 案例 3 的破甲需求）

- **生物（发条玩具虫）**：蟑螂（高速逃窜、急转）、蝗虫（跳跃、高弹性）、清道夫（厚重装甲、可固定，为"破甲实验"提供靶子）。
- **爆炸物**：小炮仗（原地引信）、冲天炮（竖直上冲）、窜天猴（定向瞄准飞行）。
- **配件**：牙签（+穿透）、大头针（++穿透、命中钉住）、绳子（连接两物体、可拽飞、超载断裂）、胶水（命中粘附再爆）。
- **场景**：一个透明盒子（单一材质；玻璃/海绵/水等材料系统进 backlog）。
- **系统**：编辑器、点燃、连锁、事故报告、回放、URL 分享码、3 个案例预设（对应 PRD 案例 1/2/3）。

## 5. 架构

```
src/
  sim/          ← 纯逻辑，零 DOM 依赖，Node 无头可测
    rng.js        种子RNG mulberry32（模拟唯一随机源）
    math.js       向量/夹取等
    body.js       圆形刚体 + 半隐式欧拉积分
    world.js      盒世界：碰撞(圆-圆/圆-墙)、绳约束、步进
    explosives.js 三种爆炸物：引信/推力/爆炸球/连锁引燃
    bugs.js       虫 AI 状态机 idle/wander/flee/panic/knocked + 破甲
    accessories.js 牙签/大头针/绳子/胶水 修饰器与约束
    sim.js        Simulation 门面：命令、事件流、统计
  game/
    catalog.js    物品目录与属性表
    encode.js     分享码：{seed,布置,命令} ↔ base64url ↔ URL hash
    replay.js     快照环形缓冲 + 事故报告生成
    scenario.js   案例1/2/3 预设 + 实验目标判定
  ui/            ← 仅浏览器侧
    render.js     Canvas 渲染（玩具风、粒子、震屏）
    particles.js  爆炸/火花/烟
    editor.js     工具箱、摆放、瞄准、点燃、报告/回放 UI
    main.js       引导 + 帧循环
server.js        零依赖静态服务器
test/            node:test 分阶段测试
```

**数据流**：编辑器产出 `entities[]`+`commands[]` → `Simulation` 以固定步长推进 → 每步产出
`events[]`（爆炸/击倒/断裂…）→ 渲染层消费事件出特效；replay 层按 tick 存快照；
报告层从事件流统计；encode 层把输入序列变分享码。

## 6. 模拟模型（关键数值，v1 调参基线）

- 世界：盒内 300×180 单位(1u≈1cm)，重力 g=560 u/s²，固定 dt=1/60s。
- 刚体：圆形近似；属性 x,y,vx,vy,angle,angVel,mass,radius,restitution,drag,static。
- 碰撞：圆-圆冲量法+位置修正，圆-墙反弹（墙 restitution 0.5）；地面摩擦。
- **爆炸球**：`falloff = max(0, 1 - d/radius)`；
  冲量 `Δv = power × 8 × falloff / max(mass,0.5)`（径向+随机自旋）；
  伤害 `dmg × falloff`，对装甲目标乘 `1 - armor×(1-pierce)`。
- **连锁引燃**：爆炸半径内的未点燃爆炸物被引燃，引信 = 2~6 tick 随机 → 波纹式连环。
- **虫 AI**（不为聪明，为不可预测，PRD §12）：
  - 蟑螂：wander 60~90 u/s，0.4~1.2s 随机急转；受惊 flee 1.5s；近距离 panic 乱窜。
  - 蝗虫：静伏，0.8~2s 随机跳；restitution 0.7（会弹）。
  - 清道夫：armor 0.6、hp 90、默认固定不动。
  - knocked（玩具故障）：翻壳+火花+抽搐，静止成道具，仍参与碰撞。
- **爆炸物**：
  - 小炮仗：点燃后引信 0.9~1.5s，末期乱蹦；power 55 / radius 60 / dmg 45。
  - 冲天炮：竖直向上推力 0.55s 燃尽或撞顶即爆；power 70 / radius 70 / dmg 55。
  - 窜天猴：沿瞄准轴推力 0.9s+横向摆动；撞任何东西即爆；power 45 / radius 50 / dmg 35。
- **配件**：牙签 pierce 0.45/质量+0.1；大头针 pierce 0.8+命中钉住 0.25s 再爆；胶水命中粘附直至引信结束；绳子=距离约束(rest×1.8 拉断，计"意外事件")。
- **点燃方式**：①「点燃!」按钮按摆放顺序 0.35s 间隔依次点燃；②运行中点击未点燃爆炸物立即点燃（记入 commands，分享可复现）。
- **事故报告**：最后一次爆炸/击倒后 3s 平静 → 冻结 → 报告卡：连锁 ×N、击倒玩具 ×N、意外事件 ×N、单次最高冲击；#编号=seed。
- **回放**：20Hz 快照环形缓冲 12s；报告触发后 0.5× 速回放（REPLAY 水印），爆炸闪光按事件时间轴重放。
- **分享码**：`{v,seed,w,h,ents,ropes,cmds}` → base64url → `index.html#e=…`，打开即重建同一实验；确定性保证看到同一场事故。

## 8. 风险与对策

- **"看着好玩 ≠ 玩着好玩"（PRD §21）**：一切以"想法→结果 ≤ 2 分钟"为准绳；一键重跑同种子做对照实验是核心交互。
- **物理调参发散**：所有手感参数集中在 catalog/explosives 常量表，测试守护下可快速迭代。
- **确定性被破坏**：模拟层禁用 `Math.random`/`Date.now`/浮点迭代顺序不稳定结构；用双跑校验和测试守护。
